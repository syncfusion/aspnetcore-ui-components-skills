# Icons – ASP.NET Core Floating Action Button

## Basic Icon

```cshtml
<ejs-fab 
    id="fab" 
    iconCss="e-icons e-plus-icon"
    cssClass="e-primary">
</ejs-fab>
```

## Icon with Text

```cshtml
<ejs-fab 
    id="fab" 
    content="Add"
    iconCss="e-icons e-plus-icon"
    cssClass="e-primary">
</ejs-fab>
```
